# Code of Conduct

This project follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.

## Our pledge

We want participation to be free of harassment for everyone, regardless of experience level, background, identity, or the tools they use.

## Expected behaviour

- Assume good intent; critique code and conclusions, not people.
- Keep discussions technical: reproducible inputs, observed output, expected output.
- Respect the legal and ethical boundaries in [DISCLAIMER.md](DISCLAIMER.md). Requests to help with unauthorized cracking, malware development, or evading someone else's defenses will be closed.

## Unacceptable behaviour

- Harassment, personal attacks, discriminatory language.
- Publishing others' private information.
- Posting live malware, stolen data, or credentials.
- Sustained disruption of issues or pull requests.

## Enforcement

Report incidents to **lingbol088@gmail.com**. Maintainers may remove comments, close threads, or block accounts. Reports are handled confidentially.
